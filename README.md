# Car Showroom Sales Performance Analysis Using Microsoft Excel

An intermediate-level Excel data analysis project exploring car showroom bookings, deliveries, vehicle brands, revenue, monthly booking trends, and branch performance.

> **Dataset note:** This is a fictional, synthetic practice dataset created for learning and portfolio demonstration. It does not contain real dealership transactions or verified market prices.

## Project Overview

The workbook contains **600 sample booking records** and uses Microsoft Excel formulas, PivotTables, charts, KPI cards, and slicers to summarize showroom performance.

## Workbook Structure

The Excel workbook contains three worksheets:

- **Car_Showroom_Data** – the complete transaction-level dataset (600 records and 27 columns).
- **Pivot_Analysis** – summarized analyses used to compare brands, branches, booking status, and monthly bookings.
- **DASHBOARD** – KPI cards and visualizations for presenting the findings.

## Dashboard Highlights

- Revenue by Car Brand
- Booking Status Distribution
- Monthly Booking Trend
- Branch-wise Revenue
- KPI cards for bookings, deliveries, revenue, pending and cancelled bookings, and average sale value
- Filters for City, Car Brand, Booking Status, and Fuel Type

## Key Metrics and Findings

- Total bookings: **600**
- Delivered cars: **492**
- Pending bookings: **62**
- Cancelled bookings: **46**
- Delivered sales revenue: **₹64.56 crore**
- Average sale value per delivered car: **₹13.12 lakh**
- Highest revenue-generating brand in this sample: **Mahindra** (approximately **₹14.75 crore**)
- Highest revenue-generating branch in this sample: **Thane West** (approximately **₹9.41 crore**)
- Highest monthly booking count in this sample: **July 2025**, with **25 bookings**

## Tools and Excel Features

- Microsoft Excel
- Excel formulas: `COUNTA`, `COUNTIF`, `SUMIFS`, `IFERROR`
- PivotTables and PivotCharts
- KPI cards
- Interactive slicers
- Data formatting and visualization

## How to Use

1. Download `Car_Showroom_Sales_Analysis.xlsx`.
2. Open it in Microsoft Excel. Desktop Excel is recommended for full PivotTable and slicer interaction.
3. Review `Car_Showroom_Data` to understand the fields.
4. Explore `Pivot_Analysis` to see the summarized results.
5. Open `DASHBOARD` to review the KPIs, charts, and filters.

## Project Objective

The objective is to demonstrate how spreadsheet tools can transform transaction-level data into useful business summaries, comparisons, trends, and a presentation-ready dashboard.
